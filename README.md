# Smart Sales Data Manager
## نظام ذكي لتنظيف وتحليل بيانات المبيعات

## وصف المشروع

Smart Sales Data Manager هو تطبيق يعمل من خلال سطر الأوامر (CLI)، وتم تطويره باستخدام لغة Python بهدف تنظيف وتحليل بيانات المبيعات المخزنة في ملفات CSV.

يقوم التطبيق بقراءة بيانات المبيعات، ومعالجة البيانات الناقصة، وإزالة السجلات المكررة، ثم إجراء عمليات تحليل على البيانات، وأخيرًا حفظ البيانات المنظفة في ملف إخراج.

تم تطوير المشروع كتطبيق عملي لتطبيق مفاهيم الدورة، ومنها:

- أوامر Linux
- Git و GitHub
- Clean Code
- Software Engineering
- Type Hints
- Automated Testing
- Vibe Coding باستخدام الذكاء الاصطناعي

---

## أهداف المشروع

يهدف المشروع إلى تطبيق المفاهيم البرمجية بشكل عملي من خلال بناء تطبيق منظم وقابل للصيانة، مع استخدام Git لتتبع مراحل التطوير، والاختبارات الآلية للتحقق من صحة البرنامج.

## المزايا

يقدم التطبيق المزايا التالية:

- قراءة بيانات المبيعات من ملفات CSV.
- معالجة القيم الناقصة في كمية المبيعات.
- إزالة السجلات المكررة.
- حساب إجمالي عدد السجلات.
- حساب إجمالي قيمة المبيعات.
- تحديد المنتج الأعلى مبيعًا.
- حفظ البيانات بعد تنظيفها.
- عرض نتائج التحليل في الطرفية (Terminal).
- استخدام بنية برمجية منظمة وقابلة للتطوير.
- استخدام Type Hints لتحسين وضوح الكود.
- وجود 15 اختبارًا آليًا باستخدام pytest.

## مسؤولية الملفات

### io.py

مسؤول عن عمليات إدخال وإخراج البيانات، مثل قراءة ملفات CSV وحفظ البيانات الناتجة.

### cleaning.py

مسؤول عن تنظيف بيانات المبيعات، ومعالجة القيم الناقصة، وإزالة السجلات المكررة.

### analysis.py

مسؤول عن تحليل بيانات المبيعات وحساب الإحصائيات، مثل إجمالي المبيعات وتحديد المنتج الأعلى مبيعًا.

### cli.py

مسؤول عن تنسيق سير عمل التطبيق وتشغيل العمليات بالترتيب وعرض النتائج في الطرفية.

### tests/

يحتوي على الاختبارات الآلية التي تتحقق من صحة وظائف التطبيق المختلفة.

### .github/copilot-instructions.md

يحتوي على تعليمات المشروع التي يتم استخدامها لتوجيه مساعد الذكاء الاصطناعي أثناء عملية Vibe Coding، مع تحديد قواعد Clean Code والاختبارات وبنية المشروع.

## تثبيت المشروع

أولًا يتم استنساخ المستودع من GitHub:

    git clone git@github.com:abohussien/smart-sales-data-manager.git

الدخول إلى مجلد المشروع:

    cd smart-sales-data-manager

إنشاء بيئة افتراضية:

    python3 -m venv .venv

تفعيل البيئة الافتراضية:

    source .venv/bin/activate

تثبيت المشروع:

    pip install -e .

تثبيت pytest:

    pip install pytest

---

## تشغيل التطبيق

بعد تفعيل البيئة الافتراضية، يتم تشغيل التطبيق باستخدام:

    python -m src.sales_manager.cli

مثال على المخرجات:

    Smart Sales Data Manager
    ------------------------
    Total records: 9
    Total sales: 2610.0
    Top product: Laptop
    Result saved: data/output/clean_sales.csv

## Clean Code وهندسة البرمجيات

تم تطبيق عدد من مبادئ Clean Code وهندسة البرمجيات في المشروع، ومنها:

### فصل المسؤوليات

تم فصل عمليات قراءة البيانات وتنظيفها وتحليلها وتشغيل التطبيق في ملفات مستقلة.

### مبدأ المسؤولية الواحدة

كل وحدة برمجية مسؤولة عن وظيفة محددة، مما يجعل الكود أسهل في الفهم والصيانة.

### DRY

تم تجنب التكرار غير الضروري في الكود.

### أسماء واضحة

تم استخدام أسماء واضحة ومعبرة للملفات والدوال والمتغيرات.

### الدوال الصغيرة

تم تصميم الدوال بحيث تكون مركزة على مسؤوليات محددة قدر الإمكان.

### Type Hints

تم استخدام Type Hints لتوضيح أنواع البيانات التي تستقبلها الدوال وتعيدها.

## Vibe Coding

تم استخدام الذكاء الاصطناعي كمساعد أثناء عملية التطوير وليس كبديل عن المبرمج.

تم استخدام Agent من أجل:

- مراجعة بنية المشروع.
- مراجعة تطبيق مبادئ Clean Code.
- اقتراح التحسينات الممكنة.
- إضافة Type Hints وفق شروط محددة.
- الالتزام بتعليمات المشروع الموجودة في:

    .github/copilot-instructions.md

تمت مراجعة التغييرات التي اقترحها الذكاء الاصطناعي قبل اعتمادها، كما تم تشغيل الاختبارات بعد التعديلات للتأكد من عدم حدوث أخطاء.

## أمان البيانات

يستخدم المشروع بيانات تجريبية (Synthetic Data) لأغراض التدريب والاختبار.

لا ينبغي إضافة:

- كلمات المرور.
- مفاتيح API.
- بيانات الاعتماد.
- البيانات الخاصة أو الحساسة.

كما يتم استخدام ملف `.gitignore` لمنع الملفات غير المطلوبة من الدخول إلى مستودع Git.
